# rainshot 0.4.7 修改記錄

- 間隙選區改為完整局部群組，不再限制只合併兩個元素；支援三個、四個、五個及更多已探測到的鄰近元素。
- 支援一排、一列、L 形、網格及寬高不同的混合排列；外框依所有成員的最左、最上、最右、最下邊界計算，保留共同父框裁切。
- 預選完整群組，Tab 再切換到更大的父層。游標直接命中單一元素時仍選該元素。
- 搜尋區域在選定最近元素對後固定，容許與區域相交的大型元素加入，但不因加入成員而擴張區域，避免連鎖選取整頁。
- 修正網格間隙靠邊時選到過多格子的情況，選區提示改為「指向控件或元素間隙」。

## 0.4.6 已發布功能

- 一般設定加入桌面輔助功能狀態，以及「啟用更多軟體的元素識別」。Firefox、Qt 等軟體在桌面未啟用輔助功能時可能不公開元素；按鈕只啟用 IsEnabled，保留朗讀設定，非同步確認結果並顯示錯誤。部分軟體需重啟。
- 修正 GTK 捲動清單的無效 viewport 座標，沿已驗證父框找到可見列；子控件仍檢查可見性與裁切。
- 改善深層控件、巢狀兄弟節點的查詢預算，主行程只有視窗框架時繼續查找已驗證的相關 renderer。
- 初次沒有元素資料時延遲重試一次，之後滑鼠移動仍按正常延遲查詢，保留 Tab 選定範圍。
- 游標放在相鄰元素的間隙時，提供兩者的共同外框；支援左右、上下排列，保留父框裁切，排除隱藏、過遠或沒有對齊的控件。
- Firefox、Chromium、GTK 3 與 Qt 5 的隔離原生測試通過；仍無法保證所有自繪介面或 Canvas 的元素識別。

## 0.4.5 已發布功能

- 保存成功後立即關閉貼圖（包含釘住的貼圖），只保留獨立、可點擊開啟本次保存資料夾的提示。通知由應用持有，貼圖銷毀後仍能點擊；逾時、取代或退出時清理。取消或保存失敗時保留貼圖。
- GIF / WebP 錄製完成後套用相同流程，不重新顯示或啟用即將關閉的貼圖。
- 開始下一次截圖或錄製前清除獨立保存提示，避免將程式自己的提示截入圖片。
- 找到預設 Chromium 的實際原因：AT-SPI 原本只提供視窗框架，網頁輔助功能尚未啟用。對命中視窗正常查詢關係資訊，讓 Chromium 按需啟用元素，再更新快取與有界等待；不修改啟動參數或持久設定。
- 補上非元件根容器的有界搜尋，找到指定行程與視窗後立即命中查詢，保留遍歷預算。Canvas 或未公開的元素仍可能需要手動框選。

## 0.4.4 已發布功能

- 圖片、另存圖片及 GIF / WebP 錄製保存成功後，提示顯示「點擊開啟資料夾」。提示預設在右下角，可依設定放在螢幕四角；點擊後使用系統預設檔案管理器開啟該檔案所在資料夾。
- 可點擊提示不會被未釘住貼圖的外部點擊偵測誤判；提示逾時或被其他狀態取代後會清除舊動作。
- 一般提示維持滑鼠穿透；可點提示同步更新 Qt 屬性與原生輸入旗標，讓從一般提示切換而來的保存提示也能接受點擊。
- 「設定 → 一般設定」新增「每次保存圖片時選擇路徑（保存按鈕 / 保存快捷鍵）」開關，預設關閉。開啟後每次選擇位置與 PNG / JPEG / WebP 格式，取消時不寫入檔案；手動選擇不改動預設儲存資料夾，保存提示會開啟本次實際保存位置。
- 保存位置開關即時生效，已開啟的貼圖不用重新截取；GIF / WebP 錄製仍存入預設資料夾。
- 自動選區補全深層命中元素的祖先、依可見父框裁切，命中介面失效時有限度檢查子元件；支援同 UID 且可驗證為視窗行程子行程的瀏覽器 renderer，改善原生像素與 Qt 邏輯座標換算。幾何探測子行程上限 1,500 ms、內部 800 ms / 160 節點，不讀文字或修改瀏覽器設定。
- 選區旁顯示候選編號 / 總數，Tab 可切換父層、視窗與螢幕；選定後在框內移動游標保留範圍，Shift 放開後恢復吸附，也可直接拖曳自訂。網頁元素仍依賴瀏覽器提供 AT-SPI，Canvas 或未暴露的 DOM 無法保證取得。
- 功能驗證記錄見 `VALIDATION.md`。
