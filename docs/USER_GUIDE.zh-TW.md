# rainshot 0.4.7 使用指南（繁體中文）

Ubuntu / Linux Mint 的原生 Qt 截圖工具。截完直接顯示可操作的貼圖；右鍵點擊系統匣圖示可開啟深色設定、截圖記錄、快捷鍵與安裝指令。

## 安裝與升級

先在系統匣退出執行中的 rainshot，再執行：

```bash
sudo apt install --reinstall ./rainshot_0.4.7_all.deb
rainshot
```

0.4.7 將間隙選區擴充為多個相鄰元素的共同外框，可一次框住三個、四個或更多局部相鄰元素，支援 L 形、網格與寬高不同的混合排列。外框由所有成員的最左、最上、最右、最下邊界決定，預選完整群組；Tab 可再切換至更大的父層區域。群組只在游標附近搜尋，避免沿相鄰元素一路擴張至整個頁面。

0.4.6 改善 Firefox、GTK 與 Qt 的元素選區。在「設定 → 一般設定」按「啟用更多軟體的元素識別」，允許 Firefox、Qt 等軟體提供元素範圍；這會啟用桌面的輔助功能，不會啟動朗讀。部分已開啟的軟體需要重啟。也修正 GTK 捲動清單的無效中間座標、深層容器漏選，首次沒有資料時會延遲重試一次。

0.4.5 保存成功後立即關閉貼圖，只留下可點擊開啟保存資料夾的獨立提示。自動選區會透過正常的 AT-SPI 輔助功能查詢，請 Chromium 按需提供網頁元素，不需加啟動參數。

0.4.4 加入手動保存成功提示的「點擊開啟資料夾」，以及「每次保存圖片時選擇路徑」設定開關（預設關閉）。保存按鈕與截圖後的保存快捷鍵皆套用此設定。

0.4.3 修正 X11 / Cinnamon 釘住貼圖無法拖曳到其他工作區：貼圖交由視窗管理器移動，並維持無邊框、置頂及不顯示於工作列。

0.4.2 起使用單一 rainshot 名稱，移除舊命令別名與舊設定匯入程式。從 0.4.0 升級時，套件管理器會移除舊別名；自行建立的桌面快捷鍵請改綁 `rainshot --capture`。無參數啟動只待命，不觸發截圖。沒有系統匣的桌面會顯示設定入口。

```bash
rainshot --capture       # 區域截圖，可綁定系統快捷鍵
rainshot --scroll        # 選區後直接開始長截
rainshot --record        # 選區後設定 GIF / WebP 錄製
rainshot --settings      # 設定
rainshot --history       # 記錄
rainshot --tray          # 只在背景待命
rainshot --diagnose      # 環境診斷，不截圖
rainshot --quit
```

## 截圖後的操作

點擊其他地方會關閉臨時貼圖。按 P 釘住後保留；移開滑鼠收起工具列，移回圖片繼續操作。滾輪縮放，Ctrl+滾輪調整透明度，拖曳移動。提示位於螢幕四角之一，可在設定更改位置或停用；開始下一步後自動消失。

| 快捷鍵 | 功能 |
|---|---|
| P | 釘住 / 取消釘住 |
| S | 連續捲動長截圖 |
| O | 在原圖片上識別、選取文字 |
| T | 翻譯選取文字；未選取則翻譯全部 |
| Q | 本機二維碼識別，可複製；網址提供「開啟」按鈕 |
| I | 開啟 / 結束像素放大取色模式 |
| 方向鍵 / Enter | 取色時逐像素微調 / 複製 HEX |
| C | 取色模式中複製目前像素 HEX |
| G | 設定 GIF / 動態 WebP 區域錄製 |
| Ctrl+C / Ctrl+S | 複製 / 儲存圖片；選字時複製文字 |
| Ctrl+A | OCR / 譯文全選 |
| Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y） | 上一步 / 下一步 |
| X | 在圖片中直接輸入文字 |
| Enter / Shift+Enter | 確認輸入 / 換行（Esc 取消） |
| Esc | 取色時退出模式；其餘時候關閉貼圖 |

這些是預設按鍵，只在貼圖取得焦點時生效。「設定 → 截圖後按鍵」可修改功能鍵和標註鍵，清空可解除，也可恢復預設值。套用前會檢查重複按鍵與全域截圖按鍵衝突；已開啟的貼圖及提示立即更新。方向鍵、Enter 保留給取色与文字編輯。

標註列提供矩形、箭頭、畫筆、文字、螢光、馬賽克、遮蓋等工具。移動與裁切按鈕已移除；一般模式仍可拖曳貼圖。選中色有外框與勾選標記，大小用滑軌調整。列內提供上一步、下一步按鈕；關閉標註列立即停止繪圖。

文字標註在點擊位置直接編輯，背景透明，支援中文輸入法、游標與文字選取；Enter 確認，Shift+Enter 換行，Esc 取消。輸入期間功能快捷鍵暫停，Ctrl+Z 操作正在輸入的文字；確認後 Ctrl+Z 撤銷整段文字標註。

按滴管按鈕或 I 才開始取色。11×11 像素放大鏡以白框標示中心像素，顯示 `#RRGGBB`、RGB 與座標；方向鍵每次移動一個原始像素，Enter、C（可自訂）或點擊複製；成功後立即退出取色並收起放大鏡。縮放後仍讀取原像素；放大鏡、工具列與 OCR 選取底色不會寫入儲存圖片。滑鼠離開圖片時隱藏放大鏡。

「設定 → 一般設定」可瀏覽或輸入預設儲存資料夾。開啟「每次保存圖片時選擇路徑」後，保存按鈕及保存快捷鍵（預設 Ctrl+S）會讓你選擇檔案位置與 PNG / JPEG / WebP 格式；取消時不保存，選擇其他位置也不改動預設資料夾。此選項預設關閉，關閉時圖片直接存入預設資料夾。GIF / WebP 錄製繼續使用預設路徑；另存與記錄保存也從這個資料夾開始。無效或無法寫入的路徑不會取代已套用的設定。

圖片、另存圖片及 GIF / WebP 錄製保存成功後，立即關閉該貼圖（包含釘住的貼圖），只留下約 6.5 秒的獨立提示。點擊「開啟資料夾」會用系統預設檔案管理器開啟本次實際保存的位置。提示預設在右下角，也遵循四角設定；取消或保存失敗時保留貼圖。

截圖記錄維持雙擊重新開啟貼圖。右鍵提供「開啟（系統預設程式）」與「保存副本…」；保存保留原檔格式、畫質及動畫，不改動原檔。

二維碼中的完整 HTTP / HTTPS 網址可用「開啟」交給預設瀏覽器；多個網址可先選擇。文字、Wi-Fi 等內容保留供複製，不會當成程式或本機檔案執行。

## 以圖搜圖

按圖片搜尋圖示，選 Google Lens 或 Bing，按「開啟搜尋」。貼圖會自動釘住：

1. 在搜尋頁面按相機圖示，打開圖片上傳區。
2. 將貼圖附屬工具列的「拖曳截圖到網頁」按住，拖入網頁上傳區。
3. 若瀏覽器不接收拖放，按「複製路徑」，在網頁的上傳檔案對話框按 Ctrl+L 後貼上。

搜尋圖片是目前裁剪與標註後的 PNG。只有拖入網頁或選擇上傳檔案時，圖片才會送往所選服務；rainshot 不會在背景上傳。這是瀏覽器交接流程，並非直接在貼圖內呈現搜尋結果。私有搜尋快取在下次準備圖片時清理，保留最近 24 小時內最多 20 個 / 256 MB，加上正在準備的圖片。

流程依據 [Google 以圖搜尋說明](https://support.google.com/websearch/answer/1325808) 與 [Bing 視覺搜尋說明](https://support.microsoft.com/en-us/bing/using-bing-visual-search)。

## 連續捲動截圖

1. 框選網頁或文件的內容區，**標註與裁剪前按 S**。
2. 貼圖隱藏，原頁面重新顯露；直接使用原頁面的滾輪。旁邊顯示累積長圖預覽。
3. 盡量讓相鄰畫面保留一半重疊。引擎只接合通過特徵位移與文字邊緣檢查的畫面；反向捲動不追加，失去重疊時會提示捲回。
4. 按完成或 Ctrl+Enter，長圖回到貼圖上，可繼續選字、編輯、複製與儲存。Ctrl+Esc 取消。

「自動捲動」開啟後，滑鼠移入選區才送出滾輪事件，移出暫停；前方視窗改變或接合失敗時停止自動捲動。固定頁尾會先移除、接合後再保留一次。

選區旁空間不足時，預覽會收起。若仍沒有空間，按鈕位於選區右上角：滑鼠移開後隱藏並開始擷取，移回該位置顯示按鈕並暫停擷取，避免把按鈕截入長圖。系統匣也提供「完成進行中的長截 / 錄製」。Ctrl+Enter / Ctrl+Esc 僅在工作期間註冊；若遭占用，仍可使用按鈕。

目前為垂直長截：不支援橫向拼接、無限跳頁、跨過無重疊內容或任意動態視訊的可靠拼接。上限為單邊 32,760 px / 8,000 萬像素。

## 自動選區在 Linux 上的支援

X11 下，按截圖鍵後滑鼠指向視窗即可預選範圍。AT-SPI 可用時，嘗試取得按鈕、輸入欄及網頁控件的可見範圍，選區旁顯示目前候選編號 / 總數。游標放在相鄰元素的空隙或交會處，會預選局部群組的共同外框，成員不限於兩個；支援一排、一列、網格、L 形與寬高不同的混合排列。外框取全部成員的最左 / 最上至最右 / 最下邊界，並保留共同父容器裁切。群組需足夠接近且位於固定的游標附近搜尋區域，不會沿整個頁面連鎖擴張。直接指向元素時仍選該元素。Tab 從小元素或完整群組切換至父層範圍、視窗與螢幕；選定範圍後，在框內小幅移動游標會保留選區。點擊確認，或直接拖曳自訂；Shift 暫停吸附，放開後恢復。

0.4.4 補全命中元素的祖先範圍，依可見父容器裁切，並在命中介面失效時有限度檢查子元件；也改善多行程瀏覽器及螢幕像素 / Qt 座標換算。網頁元素仍取決於瀏覽器提供 AT-SPI 輔助功能樹，Canvas 或未暴露的 DOM 無法保證取得。沒有資料或查詢逾時時保留視窗選區；啟動與選區查詢不會自動修改瀏覽器或桌面的輔助功能設定。

0.4.5 修正預設 Chromium 只公開視窗框架、沒有網頁元素的情況：對命中的視窗做一次正常的輔助功能關係查詢，讓 Chromium 按需啟用元素資訊，再有界等待與更新快取。也支援根視窗外的非元件容器，找到指定行程後立即查詢，避免無關應用耗盡時間。實際桌面的測試範圍與限制見驗證記錄。

0.4.6 找到 Firefox 未公開元素的原因：桌面 `org.a11y.Status.IsEnabled` 關閉時，Firefox 可能連 AT-SPI 應用節點都不建立。一般設定新增狀態顯示與「啟用更多軟體的元素識別」按鈕，只有按下時才啟用系統輔助功能，並確認服務回傳已啟用；不改動 Firefox profile，也不更改朗讀狀態。這是桌面層設定，GNOME / Mint 可能持久保存，之後可從系統輔助功能設定管理。Qt 5 等既有行程可能需要關閉後重開。

0.4.7 的本機 Chromium / Firefox 測試另涵蓋三元素 L 形、四元素網格、四元素不規則排列，以及高 600 px、寬 500 px 成員的混合外框。完整群組預選與 Tab 父層切換皆通過。

| 軟體類型 | 既有原生實測範圍 |
|---|---|
| Chromium | 未加強制 accessibility 參數的按鈕、圖片、卡片、文章、間隙共同外框；選區覆蓋及 Tab 父層 |
| Firefox | 桌面輔助功能啟用後，同樣網頁元素、間隙共同外框與選區覆蓋流程 |
| GTK 3 | 按鈕、輸入欄、標籤、文字編輯、捲動清單 / 樹、巢狀控件、多視窗及間隙共同外框 |
| Qt 5 | 輔助功能啟用後，同樣常用控件、捲動清單 / 樹、多視窗及間隙共同外框 |

這些實測使用隔離的本機網頁與測試軟體，不能保證每個應用都公開元素。自繪介面、Canvas、遊戲或未提供 AT-SPI 的 Electron 應用仍可能只選到整個視窗，可拖曳手動選區。Wayland 此版仍使用系統選區，沒有新增任意應用的元素吸附。

## 翻譯與 OCR

譯文直接覆蓋 OCR 的原文字行，並可用滑鼠選取、Ctrl+C 複製；複製或儲存圖片也會包含譯文。按「原文」恢復原圖片與 OCR 選取。字高以原文字框為依據，譯文較長時縮小至框內；背景色由文字框周圍取樣，複雜圖案背景不會像圖片修復那樣完整重建。

為保留原位置，翻譯按 OCR 行逐一請求，最多 80 行 / 5,000 字、整批 120 秒；長段落可能因分行失去部分上下文。所有行成功後才一起套用，失敗或取消時保留原圖。翻譯後可继续取色與標註；實際加入標註時將譯文合入可撤銷的影像歷史。

預設 **Google（免金鑰）**，也可選 **Microsoft（免金鑰）**，採用 Snow Shot 現有的網頁翻譯入口。這兩項不需申請 API 金鑰，但需要可連線的網路；入口可用性由服務端決定。只在按下翻譯時傳送文字，不傳圖片，也不會在失敗後自動改送另一家服務。

其他選项：DeepL API Free / Pro、有道智雲、DeepSeek、通義千問 Turbo / Plus / Max、自訂 Chat Completions 相容服務、LibreTranslate。這些服務依各自配置使用金鑰或本機端點。各服務分別保留設定；金鑰只放在本次行程記憶體，或使用 `RAINSHOT_KEY_服務代碼` 環境變數。

通義千問對應 Snow Shot 中的 Qwen Turbo / Plus / Max 選項，使用阿里雲百煉的 Chat Completions API，**需要自己開通的阿里雲金鑰**。預設北京端點；國際區金鑰需在 API 地址改填 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions`，亦可使用控制台提供的業務空間專屬地址。模型欄可編輯，金鑰與模型可用性依帳號及地域決定。參見 [阿里雲官方 API 文件](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)。

OCR 在本機執行，不需翻譯 API 金鑰：

- **RapidOCR / PP-OCRv4**：使用 Paddle OCR 的 ONNX 模型，與 Snow Shot 所用模型系列相近。可選安裝；自動模式在指定 Python 路徑已存在時優先使用。
- **Tesseract**：保留為系統套件引擎，可安裝繁體、簡體及英文語言包。

到「設定 → OCR 與指令」可逐條複製安裝命令。RapidOCR 建議獨立環境：

```bash
sudo apt install python3-venv
python3 -m venv "$HOME/.local/share/rainshot/ocr"
"$HOME/.local/share/rainshot/ocr/bin/pip" install rapidocr-onnxruntime==1.4.4 "numpy<2" "opencv-python<4.11" onnxruntime==1.20.1
```

模型包含在此 RapidOCR 套件內；完成安裝後，识別時不連網。若換了安裝目錄，請同步修改 OCR 頁的 Python 路徑。識別結果仍可能有錯字，字體、圖片解析度與排版會影響準確度。

```bash
sudo apt install tesseract-ocr tesseract-ocr-chi-tra tesseract-ocr-chi-sim tesseract-ocr-eng
```

## GIF / 動態 WebP

按 G 或從系統匣選擇錄製區域。可選輸出格式、5–20 FPS、1–120 秒、輸出寬度上限與是否包含滑鼠。按開始後錄製的是原螢幕區域，貼圖會隱藏。

**Ctrl+Enter 停止，Ctrl+Esc 取消**；也能使用側邊或系統匣的完成按鈕。滿版選區沒有空間放側邊按鈕時，錄製期間隱藏控制列，使用快捷鍵或系統匣完成。處理中的 GIF / WebP 可取消。

影片先寫入私有暫存資料夾，經 FFmpeg 編碼後才原子寫入一般設定中的儲存資料夾（預設「圖片/rainshot」）。成功後關閉對應貼圖，獨立提示可開啟保存資料夾。輸出為無音訊、無限循環動畫；暫存錄影上限 512 MB。每次錄製限單一螢幕。

## 桌面相容性

| 功能 | X11 | Wayland |
|---|---|---|
| 區域截圖 | 原生選區、視窗 / 元素吸附 | 系統 Screenshot Portal 授權選區 |
| 貼圖、標註、OCR、翻譯、二維碼、取色 | 支援 | 支援，定位 / 失焦行為依合成器 |
| 連續長截、GIF / WebP 錄製 | 支援 | 此版尚未提供 PipeWire 錄製與連續擷取 |
| 全域快捷鍵 | 程式內設定 | 在桌面鍵盤設定綁定命令 |

本版實機驗證環境為 Linux Mint 21.3 Cinnamon / X11、雙螢幕、100% 縮放。Ubuntu Wayland 的基本截圖仍走 Portal；若要使用此版連續長截與錄製，請登入 X11 / Ubuntu on Xorg 工作階段。混合 DPI 的圖像合成有單元測試，但未在混合 DPI 實機上驗證新增的視窗吸附與錄製。

## 從原始碼執行

```bash
sudo apt install python3-pyqt5 python3-pyqt5.qtsvg python3-numpy python3-opencv python3-pyatspi libqt5svg5 qtwayland5 libx11-6 libxi6 libxtst6 libzbar0 ffmpeg
./run.sh
```
